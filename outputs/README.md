# `outputs/` — Everything "visible": charts, maps, and metrics

All files generated by the notebooks (charts, maps, metrics, SHAP results, the final
deployed map) are saved here, organised by type:

- **`figures/climate/`** — climate charts and their relationship with fire (e.g. burned
  area vs. ENSO, burned-area time series).
- **`figures/social/`** — social/infrastructure charts (e.g. land cover and coca vs.
  burned area).
- **`maps/`** — spatial maps (fire quintiles by period, latest-year snapshot, maps with
  river/road/park/coca layers).
- **`diagnostics/`** — statistical diagnostic charts (e.g. Spearman correlation matrix
  between predictors). See [`diagnostics/README.md`](diagnostics/README.md).
- **`metrics/`** — exported model metric tables (CSV). See
  [`metrics/README.md`](metrics/README.md).
- **`shap/`** — model interpretability charts (SHAP, permutation importance) for the
  Random Forest. See [`shap/README.md`](shap/README.md).
- **`probability_map/`** — the final deployed model: the winning Random Forest (v4)
  applied to every pixel of the study nucleus, plus individual ArcGIS-ready layers. See
  [`probability_map/README.md`](probability_map/README.md).

Every notebook that produces a chart or map saves it automatically to the corresponding
subfolder (no need to move them by hand). If you re-run a notebook, the existing file is
overwritten with the latest version.
