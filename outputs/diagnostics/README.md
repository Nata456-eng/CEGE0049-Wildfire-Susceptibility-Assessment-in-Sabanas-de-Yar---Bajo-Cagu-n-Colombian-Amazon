# `outputs/diagnostics/` — Statistical diagnostics

Charts generated by [`eda/diagnosis.ipynb`](../../eda/diagnosis.ipynb):

- `spearman.png` — Spearman correlation matrix among the 10 initial candidate
  predictors. It was used to detect the redundant humidity block (`rh_pct`,
  `precip_mm`, `vpd_kPa` strongly correlated with each other), which led to dropping
  `rh_pct` and `precip_mm` from the final predictor set (see
  [`model/logistic_regression/README.md`](../../model/logistic_regression/README.md), section 4).
